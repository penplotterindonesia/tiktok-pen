# TikTokPen Portable

A portable Windows application for GRBL pen plotters and live name writing.

## What it does

### TikTok LIVE — automatic
TikTok LIVE gift/follow events can be placed into the queue automatically. The plotter writes names one by one while you continue streaming. Duplicate events are protected against double drawing.

### YouTube — manual
YouTube is manual: type the name yourself in the dashboard, press Print, and the plotter writes it. There is no automatic YouTube integration.

## Features

- No Python, pip, or dependency installation required
- One-click Windows launcher
- GRBL USB/serial connection
- Set Zero
- Pen Up / Pen Down controls
- Jog and Home controls
- Real-time STOP / feed hold
- Queue management and duplicate-event protection
- Local dashboard at `http://localhost:5014`

## Quick start

1. Download the ZIP from Gumroad.
2. Extract the complete folder.
3. Open `TikTokPen_Portable`.
4. Double-click `Start_TikTok_Pen.bat`.
5. Connect your GRBL pen plotter.
6. Select the correct COM port and press **Set Zero**.

## Requirements

- Windows 10/11 64-bit
- GRBL-compatible pen plotter
- USB/serial connection
- Pen, paper, and machine calibration

## Important notes

This repository is a product page and portfolio reference. The paid download contains the portable executable and runtime files.

Physical results depend on the individual plotter, steps/mm, pen, paper, speed, and calibration. Test on scrap paper first and never leave a connected machine unattended.

The package is tested on Windows 10/11 64-bit. macOS, Linux, Windows 32-bit, and ARM systems are not verified.
